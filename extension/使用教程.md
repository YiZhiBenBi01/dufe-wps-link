# 东北财经大学课件下载扩展 · 安装使用教程

## 这个扩展能做什么
在东北财经大学「白果云」课程详情页（`ginkgostu.dufe.edu.cn/course/detail`），一键把「只能在线预览、不能下载」的 WPS 课件，还原成可以直接下载 / 打开的**真实源站链接**。安装后页面右下角会出现一个红色按钮，点一下即可。

> 重要前提：扩展只在课程详情页生效，且需要你**已登录、能看到课件的账号**。

---

## 一、安装（Chrome / Edge，最通用）

1. 下载扩展压缩包并**解压**到任意文件夹（会得到含 `manifest.json` 的一个文件夹，记住它的位置）。
2. 在地址栏输入并打开：`chrome://extensions`（Edge 输入 `edge://extensions`）。
3. 打开页面右上角的 **「开发者模式」** 开关。
4. 点击左上角 **「加载已解压的扩展程序」**，选中**刚才解压出来的那个文件夹**（里面要有 `manifest.json`）。
   - 也可以直接把**解压后的文件夹**拖到这个页面上，效果一样。
5. 看到列表里出现「DUFEE 课件真实链接提取器」，且下面没有红色报错，就装好了。

> 说明：因为是从本地加载、不是从应用商店安装的，浏览器可能会提示「并非来自 Chrome 网上应用店」，这是正常现象，点「保留」/「继续」即可。

---

## 二、安装（Firefox）

1. 下载并解压扩展压缩包。
2. 在地址栏输入并打开：`about:debugging`。
3. 左侧点 **「此 Firefox」**。
4. 点 **「临时载入附加组件」**，然后选择：
   - 直接选**解压后的文件夹**里的 `manifest.json`；或
   - Firefox 也支持直接选 **`.zip` 压缩包**本身。
5. 载入成功后即可使用。

> 说明：Firefox 的「临时载入」在**每次重启浏览器后需重新载入一次**，属正常现象；正式上架 Firefox 商店后可常驻。

---

## 三、怎么用（下载课件）

1. 打开 `https://ginkgostu.dufe.edu.cn/course/detail`（先登录能看到课件的账号）。
2. 页面右下角出现红色 **「显示真实链接」** 按钮，角标会显示找到的链接数量。
3. 点一下按钮，弹出悬浮窗，列出本页所有课件的**真实下载链接**（不会自动跳转）。
4. 在悬浮窗里点对应课件的 **「下载」**，即可把原文件存到本地。
   - 也可以点「新标签打开」直接预览，或「复制全部链接」一次性复制。
5. 若课件列表是点开后才加载的，等列表出现再点按钮即可（每次点击都会重新扫描）。

---

## 四、常见问题

- **Q：拖进 ZIP 没反应？**
  A：Chrome / Edge 不能直接装 ZIP，必须先**解压**，再「加载已解压的扩展程序」选文件夹。Firefox 才能直接选 ZIP。
- **Q：按钮没出现？**
  A：确认当前页面是 `ginkgostu.dufe.edu.cn/course/detail`（且已登录）。扩展不会在其他网站运行。
- **Q：点下载没反应 / 提示失败？**
  A：源站有时会校验登录态或拦截；可改用悬浮窗里的「新标签打开」再在浏览器里另存为，或确认账号登录状态。
- **Q：重启浏览器后扩展没了？**
  A：开发者模式 / 临时载入的扩展在重启后可能失效，重新「加载已解压的」一次即可（Firefox 尤为常见）。
